# Постмастер — генератор постов для товаров

Небольшое Flask-приложение, которое превращает информацию о товаре в готовый
продающий пост: заголовок, эмодзи, основной текст, польза для покупателя,
призыв к действию и хэштеги. Работает локально, без базы данных.

## Возможности

- Два режима генерации с переключателем:
  - **Через ИИ** — использует OpenAI (`OPENAI_MODEL`), берёт описание
    со страницы товара по URL и обрабатывает его.
  - **По шаблону** — собирает пост по заранее заданной структуре.
- Поле URL страницы товара (необязательное, доступно только в режиме ИИ).
- Название товара, описание товара, цена или выгода, настроение поста.
- Если страница недоступна — автоматический переход на режим по шаблону.
- Если режим ИИ включён, но ключ не указан или ИИ вернул ошибку — тоже
  переключается на шаблон и показывает уведомление.
- Блок «Готовый пост» с кнопкой «Скопировать пост» и сообщением
  «Пост скопирован».
- Если нет URL, страница недоступна или описание не заполнено —
  показывается «Добавьте описание товара».

## Быстрый старт

```bash
# 1. Виртуальное окружение
python3 -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate

# 2. Зависимости
pip install -r requirements.txt

# 3. Настройки (необязательно для режима по шаблону)
cp .env.example .env

# 4. Запуск
python app.py
```

Откройте в браузере: http://127.0.0.1:5000

## Настройки `.env`

```env
OPENAI_API_KEY=ваш_ключ
OPENAI_MODEL=gpt-4o-mini
```

- Если `OPENAI_API_KEY` указан — по умолчанию активен режим **Через ИИ**.
- Если ключа нет — сайт запускается в режиме **По шаблону**, а переключатель
  ИИ отключён.

## Структура проекта

```
app.py              логика Flask, генерация поста, парсинг страницы товара
templates/
  index.html        интерфейс страницы
static/
  style.css         оформление
  script.js         переключение режимов, копирование поста
voice.md            настройки стиля постов для ИИ
.env.example        пример переменных окружения
requirements.txt    зависимости
```

## Настройка стиля

- **Для ИИ** — редактируйте `voice.md`: общий тон, длина, количество эмодзи,
  стиль заголовков и CTA, правила хэштегов, чего избегать.
- **Для шаблона** — константы в `app.py` в блоке
  «НАСТРОЙКИ СТИЛЯ ГЕНЕРАТОРА»: `MOODS`, `TEMPLATE_*`, `HASHTAG_LIMIT`.

## Частые вопросы

**Почему ИИ не отвечает и пост собран по шаблону?**
Проверьте ключ и модель в `.env`. Если регион недоступен для OpenAI или
закончился лимит, приложение автоматически переключится на шаблон и покажет
уведомление.

**Нужна ли база данных?**
Нет. Все данные живут только во время обработки запроса.
