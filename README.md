# Постмастер — генератор постов для товаров

Небольшое Flask-приложение, которое превращает информацию о товаре в готовый
продающий пост: заголовок, эмодзи, основной текст, польза для покупателя,
призыв к действию и хэштеги. Работает локально, без базы данных.

## Возможности

- Два режима генерации с переключателем:
  - **Через ИИ** — использует OpenAI (`OPENAI_MODEL`), берёт описание
    со страницы товара по URL и обрабатывает его.
  - **По шаблону** — собирает пост по заранее заданной структуре.
- Поле URL страницы товара (необязательное, доступно только в режиме ИИ).
- Название товара, описание товара, цена или выгода, настроение поста.
- Если страница недоступна — автоматический переход на режим по шаблону.
- Если режим ИИ включён, но ключ не указан или ИИ вернул ошибку — тоже
  переключается на шаблон и показывает уведомление.
- Блок «Готовый пост»:
  - текст можно **редактировать** перед копированием или публикацией;
  - кнопка «Скопировать пост» с сообщением «Пост скопирован»;
  - добавление поста в **избранное**;
  - публикация на стене сообщества **ВКонтакте**;
  - **отложенная публикация** с выбором даты и времени.
- Если нет URL, страница недоступна или описание не заполнено —
  показывается «Добавьте описание товара».

## Быстрый старт

```bash
# 1. Виртуальное окружение
python3 -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate

# 2. Зависимости
pip install -r requirements.txt

# 3. Настройки (необязательно для режима по шаблону)
cp .env.example .env

# 4. Запуск
python app.py
```

Откройте в браузере: http://127.0.0.1:5000

## Настройки `.env`

```env
# OpenAI
OPENAI_API_KEY=ваш_ключ
OPENAI_MODEL=gpt-4o-mini

# ВКонтакте
VK_ACCESS_TOKEN=токен_сообщества
VK_GROUP_ID=123456789
```

- Если `OPENAI_API_KEY` указан — по умолчанию активен режим **Через ИИ**.
- Если ключа нет — сайт запускается в режиме **По шаблону**, а переключатель
  ИИ отключён.
- Для публикации во ВКонтакте нужны оба параметра: `VK_ACCESS_TOKEN` и
  `VK_GROUP_ID`. Без них кнопки публикации и отложки отключены.
- `VK_GROUP_ID` — числовой ID сообщества без минуса и без `club/`.
- Токен создаётся в настройках сообщества: **Управление → Работа с API**.
  Нужно право публикации на стене.

## Избранное и отложенные посты

Данные хранятся локально в JSON-файлах и создаются автоматически:

- `favorites.json` — избранные посты. Добавить можно кнопкой «В избранное»,
  удалить — кнопкой «Удалить» в блоке «Избранное».
- `scheduled.json` — записи об отложенных публикациях. Пост планируется
  средствами ВКонтакте через `publish_date`, а в файл сохраняется информация
  о тексте и времени.

Отложенная публикация:

- по умолчанию подставляется время **+1 час** от текущего;
- минимальный интервал — **+10 минут**;
- запланировать пост можно кнопкой «Отложить» рядом с готовым постом.

## Структура проекта

```
app.py              логика Flask, генерация, избранное, VK, отложенные посты
templates/
  index.html        интерфейс страницы
static/
  style.css         оформление
  script.js         режимы, копирование, избранное, публикация, отложка
voice.md            настройки стиля постов для ИИ
favorites.json      избранные посты (создаётся автоматически)
scheduled.json      отложенные публикации (создаётся автоматически)
.env.example        пример переменных окружения
requirements.txt    зависимости
```

## Настройка стиля

- **Для ИИ** — редактируйте `voice.md`: общий тон, длина, количество эмодзи,
  стиль заголовков и CTA, правила хэштегов, чего избегать.
- **Для шаблона** — константы в `app.py` в блоке
  «НАСТРОЙКИ СТИЛЯ ГЕНЕРАТОРА»: `MOODS`, `TEMPLATE_*`, `HASHTAG_LIMIT`.

## Частые вопросы

**Почему ИИ не отвечает и пост собран по шаблону?**
Проверьте ключ и модель в `.env`. Если регион недоступен для OpenAI или
закончился лимит, приложение автоматически переключится на шаблон и покажет
уведомление.

**Почему не публикуется пост во ВКонтакте?**
Проверьте `VK_ACCESS_TOKEN` и `VK_GROUP_ID`, а также право токена публиковать
на стене сообщества. Подробности ошибки выводятся в консоль Flask.

**Где хранятся избранные и отложенные посты?**
В файлах `favorites.json` и `scheduled.json` рядом с `app.py`. База данных не
используется.

**Как отменить отложенную публикацию?**
Запись в `scheduled.json` — локальная история. Сама отложенная публикация
создаётся на стороне ВКонтакте, поэтому отменять её нужно в управлении
сообществом.
